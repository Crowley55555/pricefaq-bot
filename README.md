# Demo Price/FAQ Bot — AI-консультант для малого бизнеса

Telegram-бот и веб-виджет, который отвечает клиентам по прайсу и FAQ (RAG на ChromaDB), собирает заявку (имя, телефон, услуга, время) и передаёт менеджеру в Telegram. Демо — на вымышленном автосервисе «АвтоГараж».

## Задача

Малый бизнес (автосервис, салон, частная клиника, курсы) ежедневно отвечает на одни и те же вопросы: «сколько стоит?», «работаете ли в выходные?», «можно ли со своими запчастями?». Это пожирает время администратора и часть клиентов уходит, не дождавшись ответа. Нужен консультант, который:

- отвечает по прайсу и FAQ без участия человека;
- не выдумывает ответы (только то, что есть в базе);
- если не уверен — сам предлагает позвать мастера;
- собирает контакты и передаёт менеджеру.

## Решение

- **RAG на ChromaDB** по двум источникам: прайс (`data/services.csv`) и FAQ (`data/faq.json`).
- **FSM сбора заявки** (aiogram 3): имя → телефон → услуга → удобное время. Заявка сразу уходит менеджеру в Telegram (`MANAGER_CHAT_ID`) и дублируется в `data/leads.jsonl`.
- **Воронка** выбора категории с Inline-кнопками (ТО, шиномонтаж, диагностика, кузов, электрика).
- **Failover LLM** (GigaChat → YandexGPT → OpenRouter → OpenAI): работает с любым доступным провайдером из `.env`.
- **Fallback на менеджера** при низкой уверенности поиска или недоступном LLM.
- **Веб-виджет** (чистый JS, без фреймворков) + отдельный Telegram-бот как два канала одного бэкенда.
- **24 pytest-теста** (конфиг, модели, FSM, ingest, API, воронка).

## Пример диалога

**Вопрос о цене:**

```
Клиент:  Сколько стоит замена масла?
Бот:     Замена моторного масла и фильтра — от 800 ₽, ~30 минут
         (без стоимости расходников).
         [Оставить заявку] [Главное меню]
```

**Общий вопрос по FAQ:**

```
Клиент:  Работаете в выходные?
Бот:     Пн-Вс с 09:00 до 21:00 без обеда и выходных.
         В праздники — по сокращённому графику.
         [Оставить заявку] [Главное меню]
```

**Заявка через FSM:**

```
Клиент:  записаться
Бот:     Запишу вас к мастеру. Как вас зовут?
Клиент:  Иван
Бот:     Укажите телефон для связи.
Клиент:  +7 999 123-45-67
Бот:     Какая услуга?
Клиент:  Замена масла
Бот:     Когда удобно?
Клиент:  завтра вечером
Бот:     Спасибо! Заявка принята, мастер свяжется с вами в ближайшее время.

→ Менеджеру в Telegram приходит:
   Новая заявка
   Имя: Иван
   Телефон: +7 999 123-45-67
   Услуга: Замена масла
   Время: завтра вечером
   Источник: telegram
```

## Как устроено

- `main.py` — FastAPI backend. Эндпоинты `/api/chat`, `/health`, `/static/*`. Воронка выбора категории, in-memory сессии, RAG-поиск + подстановка контекста в LLM-промпт.
- `telegram_bot.py` — aiogram 3 бот. Inline-кнопки, навигация, FSM сбора лида. Шлёт заявку менеджеру через `bot.send_message(MANAGER_CHAT_ID, ...)`.
- `vector_store.py` — обёртка над `chromadb.PersistentClient`: upsert, delete, search, clear.
- `scripts/ingest.py` — читает `data/services.csv` + `data/faq.json`, формирует чанки с метаданными (`item_id`, `type`, `category`) и индексирует через `vector_store.index_chunks`. Запуск: `python -m scripts.ingest --all`.
- `llm_factory.py` — выбор провайдера по доступным переменным окружения с кешированием.
- `config.py` — все словари воронки, промпт, категории, контакты, пороги уверенности.
- `models.py` — Pydantic-модели: `Service`, `FaqItem`, `Lead` (с валидатором телефона), `ChatRequest/ChatResponse`.
- `static/widget.{html,css,js}` — встраиваемый веб-виджет (нейтральный префикс `shop-`).
- `tests/` — pytest + httpx TestClient, моки LLM и ChromaDB.

## Стек

Python 3.11+, FastAPI, aiogram 3, LangChain, ChromaDB, GigaChat / YandexGPT / OpenAI, pytest.

## Запуск

1. Скопируйте `.env.example` в `.env` и заполните хотя бы один LLM-ключ, `TELEGRAM_BOT_TOKEN` и `MANAGER_CHAT_ID`.
2. Соберите индекс:
   ```
   pip install -r requirements.txt
   python -m scripts.ingest --all
   ```
3. Запустите оба сервиса:
   ```
   docker compose up
   ```
   или без Docker:
   ```
   uvicorn main:app --reload   # в одной консоли
   python telegram_bot.py       # в другой
   ```

Виджет станет доступен на `http://localhost:8000/static/widget.html`.

## Тесты

```
pip install -r requirements-test.txt
pytest -q
```

24 теста: конфиг (воронка, промпт, контакты — 6), модели (валидатор телефона — 5), FSM сбора лида (4), ingest (CSV/JSON → чанки — 3), FastAPI endpoints `/health`, `/api/chat` (3), воронка — главное меню, back, main_menu (3).
